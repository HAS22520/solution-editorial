# 输出格式细则

三段骨架是硬约束：`## 题意` → `## 思路` → `## 代码`。本文说明每段该写什么、写多长、什么算写坏了。

## 一、题意

**目标**：让会算法的人 10 秒内知道输入输出是什么，而不需要读原题。

**写法**：陈述句 + 符号 + 约束。三种题型的模板：

| 题型 | 模板 | 例 |
|---|---|---|
| 最值 | 给定 <对象>（<约束>），求 <目标量> 的最大/最小值 | 给定长度 n 的数组 a（n ≤ 2×10^5），求非空连续子段和的最大值 |
| 计数 | 给定 <对象>，求满足 <条件> 的方案数，模 1e9+7 | 给定 n 阶网格图，求从 (1,1) 到 (n,m) 且不经过障碍的路径数 |
| 判定 | 给定 <对象> 与 <参数>，判断是否存在 <结构> | 给定 n 个区间与整数 k，判断能否选出 k 个两两不交的区间 |

**要点**：

- 约束单独给一句或挂在括号里，写成量的量级（`n ≤ 2×10^5`），不要抄"数据范围"小节。
- 原文有笔误、变量名冲突时，在题意里统一成你的符号，后文一路用同一套符号。
- 多组数据要说明一句：`共 T 组数据，Σn ≤ 2×10^5`。

**写坏了的样子**：

- ❌ 把题面复制一遍，包括"小明有一个长度为 n 的数组……"这种故事背景。
- ❌ 列"输入格式：第一行一个整数 n，接下来 n 个数"。这是转录，不是概括。
- ❌ 直接跳到做法，读者不知道你在解什么。

**长度**：1~3 行，超过 3 行说明还没抽象出来。

## 二、思路

四段式，顺序不要乱：

1. **观察**：题目结构里哪个东西可以被压缩、排序、合并、去重、单调化。
2. **转化**：把原问题化成什么等价问题（前缀和、差分、补集、二分答案、图论建模）。
3. **算法**：数据结构 + 不变量 + 关键式子。式子单独一行，用 `$$` 或行内 `$...$`。
4. **正确性与复杂度**：为什么不会漏解/错解；时间、空间。

**写法要求**：

- 每个决策后面跟理由。"用单调队列"不够，"用单调队列，因为窗口内的元素只会被右侧更大值淘汰，淘汰是单向的"才够。
- 关键式子单独一行，不要混在段落里。
- 复杂度写成 `O(n)`、`O(n log n)`、`O(n√n)`；空间要区分"额外空间"和"总空间"。

**篇幅**：中等难度 15~40 行；再长说明要么题目难，要么在灌水。

**黑名单表达**（写了等于没写）：

- "很容易想到" / "显然" / "不难发现" —— 读者卡住的就是这一步。
- "具体实现见代码" —— 那思路段存在的意义是什么。
- "时间复杂度较优" —— 没有数字。
- "用一个数据结构维护一下" —— 哪个结构、维护什么不变量。

## 三、代码

结构固定：

````markdown
### C++

```cpp
（完整可编译文件，含 include、常量、数组、main）
```

### C

```c
（完整可编译文件）
```

### Python

```python
（完整可运行文件）
```
````

**要求**：

- 每段都是**完整文件**，不是函数片段。带 `main`，能直接跑。
- 零注释。不写 `// 快读`、`# 单调队列`。
- 三段实现同一算法、同一 IO 格式，输出逐字节相同。
- 不用伪代码、不用 `...`、不留 `input your code here`。

**为什么要求完整文件**：题解的读者会直接复制去提交，片段等于没用；而注释会把"思路"和"代码"混在一起，破坏骨架。

## 四、整体检查

一篇合格的题解，删掉代码后应当仍能复现算法；删掉文字后应当仍能跑通。两者互不依赖，才叫分得干净。


## 五、公式怎么写

题解里的关键式子用 `$...$`（行内）或 `$$...$$`（独占一行），转换到 Word 后会变成原生公式。写的时候守四条：

| 规则 | 原因 |
|---|---|
| 分段函数不用 `\begin{cases}`，写成两条带条件的等式 | `cases` 转出来是没有花括号的矩阵，视觉上不像分段 |
| 需要空隙写 `\ \ `，不写 `\quad` / `\hspace` | 后两者的间距在转换时被丢弃，`a,\quad b` 会挤成 `a,b` |
| 字面连续空格用汉字表达（如"两个连续空格"） | `\text{"  "}` 里的空格被吞，渲染成 `""` |
| 公式里不要塞大段 C 代码 | `i++` 会渲染成 `i + +`，运算符间被加间距 |

正确示例：

```latex
$$\text{cell}(i,j)=\text{format}(p++),\ \ j\ge n-1-i$$

$$\text{cell}(i,j)=\text{两个连续空格},\ \ j<n-1-i$$
```

转换与验收细节见 `references/export-docx.md`。
